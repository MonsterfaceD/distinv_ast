\section{Case Studies: Exact Sampling from Fair Bits}
\label{sec:case-studies}

\subsection{Fast Dice Roller: the same proof at two levels}
\label{sec:fdr}

The Fast Dice Roller (FDR) samples uniformly from $\{0,\ldots,n-1\}$ using fair coin flips~\cite{DBLP:journals/corr/abs-1304-1916}. We use the following program-level presentation:
\begin{lstlisting}[basicstyle=\ttfamily\small,mathescape=true,frame=single]
$v := 1;\ c := 0;$
while ($v<n$) do
  $v := 2v;$
  $c := 2c$ [1/2] $c := 2c+1;$
  if ($c\ge n$) then $v:=v-n;\ c:=c-n$ else skip
end
\end{lstlisting}
On termination, $c$ is the sampled outcome. Existing distributional-invariant reasoning proves that the terminating output is uniform~\cite{zilken2026verifyingsamplingalgorithmsdistributional}; AST completes total correctness.

At the loop head, the reachable states satisfy
\begin{equation}
 0\le c<\min(v,n),\qquad 0<v<2n,\qquad n>0.
 \label{eq:fdr-support}
\end{equation}
We may reuse the stronger invariant from the partial-correctness proof, which additionally states that equal admissible $c$-values carry equal mass. Only \eqref{eq:fdr-support} is needed for termination.

Let $B_{\mathrm{FDR}}$ denote the body. For a Dirac input $\dirac{\sigma}$, its post-distribution is
\begin{align}
\post{B_{\mathrm{FDR}}}(\dirac{\sigma})
={}&\tfrac12[c<n]\bigl(
 \dirac{\sigma[v/2v,c/2c]}+\dirac{\sigma[v/2v,c/2c+1]}\bigr)\notag\\
&+\tfrac12[c\geq0]\bigl(
 \dirac{\sigma[v/2v-n,c/2c-n]}+
 \dirac{\sigma[v/2v-n,c/2c+1-n]}\bigr),
\label{eq:fdr-post}
\end{align}
where brackets are evaluated after the corresponding updates. This compact expression is the only operational calculation required by the program-level proof.

\begin{theorem}[AST of FDR]
\label{thm:fdr}
For every $n\in\mathbb{N}_{>0}$, FDR terminates almost surely.
\end{theorem}
\begin{proof}
Use the existing distributional invariant and define
\[
 v(\sigma)=
 \begin{cases}0&v\ge n,\\ n&v<n,\end{cases}
 \qquad
 u(\sigma)=
 \begin{cases}
 0&v\ge n,\\
 \left\lceil\log_2\!\left(\dfrac{n}{v-c}\right)\right\rceil&v<n.
 \end{cases}
\]
The supermartingale obligation is immediate: $n$ is unchanged and every successor is assigned either $n$ or $0$. For progress, inspect the outcome generated by the left fair branch. Before possible subtraction of $n$, both $v$ and $c$ are doubled; after subtraction their difference remains $2(v-c)$. Hence in either case the denominator of $n/(v-c)$ doubles, so $u$ strictly decreases. The left bit has probability $1/2$, giving $\varepsilon=1/2$.

For a sublevel set with $r<n$, only terminal states occur. If $r\ge n$, the invariant bounds $n\le r$, $0<v<2n$, and $0\le c<v$, so $v-c\ge1$ and $u\le\lceil\log_2 r\rceil$. All obligations of \Cref{thm:program-rule} hold.
\end{proof}

\paragraph{Comparison with the pCFG proof.}
The pCFG route is applicable and proves the same theorem. It first translates the program into a graph with separate locations for initialization, guard evaluation, doubling $v$, the coin flip, the conditional, and both subtraction assignments. One then supplies an invariant for every location. The supermartingale must be specialized to those locations, and the variant uses location-dependent expressions and offsets to decrease across all deterministic transitions. In particular, an iteration-level observation about doubling $v-c$ must be distributed over the choice and assignment nodes.

The program proof has one support invariant, two state functions, and the calculation \eqref{eq:fdr-post}. It also imports the invariant already used for output correctness. Thus FDR shows a strict proof-engineering improvement while controlling for proving power: both rules work, but the new rule matches the algorithmic abstraction.

\subsection{Fast Loaded Dice Roller: rejection without graph bookkeeping}
\label{sec:fldr}

The Fast Loaded Dice Roller (FLDR) samples outcome $i$ with probability $a_i/m$, where $a_1,\ldots,a_n$ are positive integers and $m=\sum_i a_i$~\cite{DBLP:conf/aistats/SaadFRM20}. Let $k=\lceil\log_2 m\rceil$. Preprocessing adds a rejecting outcome $n+1$ of weight $2^k-m$ and builds a compact representation $(H,h)$ of a binary decision tree. Sampling traverses the tree using fair bits; reaching $n+1$ resets the traversal to the root.

Abstracting the terminating preprocessing, the sampling loop is:
\begin{lstlisting}[basicstyle=\ttfamily\small,mathescape=true,frame=single]
while ($d < \phi_h(c)$) do
  $c := c+1;$
  $d := 2d$ [1/2] $d := 2d+1;$
  if ($H[d,c]=n+1$) then $c:=0;\ d:=0$ else skip
end
\end{lstlisting}
Here $c$ is the current depth and $d$ the node index; $\phi_h(c)$ identifies the first leaf position in row $c$. The preprocessing guarantees two facts used below: the tree height is at most $k$, and no internal node has both children equal to the rejecting leaf. Equivalently, from every enabled state at least one fair-bit successor avoids reset and advances one level towards a valid leaf.

The distributional invariant from the partial-correctness proof bounds reachable states by
\begin{equation}
 0\le c\le k,\qquad 0\le d\le n,
 \label{eq:fldr-support}
\end{equation}
and additionally records equal-mass and output-probability constraints. Again, the latter are retained for total correctness but are not consumed by AST.

\begin{theorem}[AST of FLDR]
\label{thm:fldr}
For every finite vector of positive integer weights, the FLDR sampling loop terminates almost surely.
\end{theorem}
\begin{proof}
Let $b$ be the loop guard. Define
\[
 v(\sigma)=\begin{cases}0&\sigma\not\models b,\\m&\sigma\models b,\end{cases}
 \qquad
 u(\sigma)=\begin{cases}0&\sigma\not\models b,\\k-c&\sigma\models b.\end{cases}
\]
Neither the weights nor $m$ are modified. Every post-state therefore has $v$ equal to $m$ if the loop remains enabled and $0$ otherwise, proving the supermartingale inequality.

Consider an enabled node. Each fair-bit outcome first increments $c$. If it is not the rejecting leaf, no reset occurs and $u$ decreases by one. The preprocessing property excludes the case in which both children reject. Therefore at least one of the two outcomes has smaller $u$, and its probability is $1/2$. The decrease condition holds with $\varepsilon=1/2$ even though the other outcome may reset $(c,d)$ and increase $u$ back to $k$.

Finally, on $v_{\le r}$, either $r<m$ and only terminal states occur, or $m\le r$. In the latter case $k=\lceil\log_2m\rceil\le\lceil\log_2r\rceil$, while \eqref{eq:fldr-support} gives $0\le u=k-c\le k$. Thus $u$ is bounded in every sublevel set, and \Cref{thm:program-rule} applies.
\end{proof}

This proof isolates the actual AST argument in three facts: $m$ is stable, tree height is logarithmically bounded by $m$, and at least one child avoids rejection. A direct pCFG treatment would additionally require values at the increment, choice, test, and reset locations, plus cases for both children. FLDR therefore illustrates the main contribution more strongly than FDR: the iteration-level rule turns a restart-heavy sampler into a short semantic proof.

\paragraph{From AST to total correctness.}
The reused distributional invariants establish that the terminating FDR output is uniform and that FLDR returns $i$ with probability $a_i/m$~\cite{zilken2026verifyingsamplingalgorithmsdistributional}. \Cref{thm:fdr,thm:fldr} show that the corresponding post-distributions have total mass one. Hence the partial-correctness distributions are proper output distributions, yielding total correctness for both algorithms.



\subsection{Han-Hoshi Sampling}
\label{sec:HanHoshi}
\begin{align*}
 &\progAnno{
 \Mhh=
 \{\dirac{v\mapsto 1,c\mapsto 0,r\mapsto 0}\}
 }\\
 &\WHILE{r=0}\\
 &\qquad \ass{v}{2v}\SEMICLN\\
 &\qquad
 \pchoice{\ass{c}{2c}}{\nicefrac 1 2}
 {\ass{c}{2c+1}}
 \SEMICLN\\
 &\qquad \ass{r}{\idx(c,v)}\\[-3pt]
 &\prbracecl
\end{align*}
Where
\[
 \idx(c,v)
 \coloneqq
 \begin{cases}
 i,
 & \text{if }S_{i-1}v \leq cm
 \text{ and }(c+1)m\leq S_i v
 \text{ for some }i\in\{1,\ldots,n\},\\
 0,
 & \text{if no such }i\text{ exists}.
 \end{cases}
\]

\begin{lemma}[Almost-sure termination of Han--Hoshi]
    \label{lem:han-hoshi-ast}
    Let $T$ denote the number of loop iterations executed by
    $\proghh$ from the initial state
    \[
        v = 1,
        \qquad
        c = 0,
        \qquad
        r = 0.
    \]
    Then, for every $t \in \mathbb{N}$,
    \[
        \Pr(T > t)
        \leq
        \min\left\{
            1,
            \frac{n-1}{2^t}
        \right\}.
    \]
    Consequently,
    \[
        \Pr(T < \infty) = 1,
    \]
    i.e., $\proghh$ is almost surely terminating.
\end{lemma}

\begin{proof}
    After exactly $t$ iterations, provided that the sampled path is
    conceptually continued even if the program would have terminated
    earlier, we have
    \[
        v = 2^t
    \]
    and $c$ is uniformly distributed on
    \[
        \{0,\ldots,2^t-1\}.
    \]
    The pair $(c,v)$ represents the dyadic interval
    \[
        J_{t,c}
        \coloneqq
        \left[
            \frac{c}{2^t},
            \frac{c+1}{2^t}
        \right).
    \]
    Thus, each depth-$t$ interval $J_{t,c}$ is selected with
    probability $2^{-t}$.

    Recall that the target distribution induces the partition
    \[
        I_i
        \coloneqq
        \left[
            \frac{S_{i-1}}{m},
            \frac{S_i}{m}
        \right),
        \qquad
        1 \leq i \leq n,
    \]
    of $[0,1)$.

    If the program has not terminated after $t$ iterations, then the
    selected interval $J_{t,c}$ is not completely contained in any
    target interval $I_i$. Since the intervals
    $I_1,\ldots,I_n$ partition $[0,1)$, the interval $J_{t,c}$ must
    contain at least one internal partition boundary
    \[
        q_i
        \coloneqq
        \frac{S_i}{m},
        \qquad
        1 \leq i < n,
    \]
    in its interior.

    For every fixed boundary $q_i$, at most one of the pairwise
    disjoint depth-$t$ dyadic intervals can contain $q_i$ in its
    interior. There are exactly $n-1$ internal partition boundaries.
    Hence, at most $n-1$ of the $2^t$ possible intervals can still be
    nonterminal.

    Since every depth-$t$ interval is selected with probability
    $2^{-t}$, it follows that
    \[
        \Pr(T>t)
        \leq
        (n-1)2^{-t}
        =
        \frac{n-1}{2^t}.
    \]
    Together with the trivial upper bound $\Pr(T>t)\leq 1$, this yields
    \[
        \Pr(T>t)
        \leq
        \min\left\{
            1,
            \frac{n-1}{2^t}
        \right\}.
    \]

    Finally,
    \[
        \Pr(T=\infty)
        =
        \lim_{t\to\infty}\Pr(T>t)
        \leq
        \lim_{t\to\infty}\frac{n-1}{2^t}
        =
        0.
    \]
    Therefore, $\Pr(T<\infty)=1$, and $\proghh$ is almost surely
    terminating.
\end{proof}


\begin{lemma}[Uniform AST bound for Han--Hoshi]
    \label{lem:han-hoshi-uniform-ast}
    Let $\sigma$ be a program state satisfying
    \[
        \sigma(r)=0,
        \qquad
        \sigma(v)>0,
        \qquad
        0\leq \sigma(c)<\sigma(v).
    \]
    Let $T_\sigma$ denote the number of further loop iterations of
    $\proghh$ from $\sigma$. Then, for every $t\in\mathbb{N}$,
    \[
        \Pr_\sigma(T_\sigma>t)
        \leq
        \min\left\{
            1,
            \frac{n-1}{2^t}
        \right\}.
    \]
    Hence, $\proghh$ is AST from every such state and from every
    distribution whose support consists only of such states.
\end{lemma}

\begin{proof}
    Write
    \[
        c_0=\sigma(c)
        \qquad\text{and}\qquad
        v_0=\sigma(v).
    \]
    The current interval is
    \[
        J_0
        =
        \left[
            \frac{c_0}{v_0},
            \frac{c_0+1}{v_0}
        \right).
    \]
    After conceptually exposing the next $t$ random bits, $J_0$ is
    partitioned into the $2^t$ equally likely descendant intervals
    \[
        J_{t,d}
        =
        \left[
            \frac{2^t c_0+d}{2^t v_0},
            \frac{2^t c_0+d+1}{2^t v_0}
        \right),
        \qquad
        0\leq d<2^t.
    \]
    Each descendant is selected with probability $2^{-t}$.

    If the program remains active after these $t$ iterations, then the
    selected descendant is not contained in any target interval
    $I_i$. It must therefore contain one of the $n-1$ internal
    boundaries $S_i/m$ in its interior. For each boundary, at most one
    descendant interval has this property. Consequently, at most
    $n-1$ descendants remain active, and thus
    \[
        \Pr_\sigma(T_\sigma>t)
        \leq
        \frac{n-1}{2^t}.
    \]
    Taking $t\to\infty$ proves almost-sure termination.

    Since the bound is uniform in $\sigma$, averaging it over any
    initial distribution supported on such states preserves the same
    bound. Therefore, the program is AST with respect to every such
    distribution.
\end{proof}
