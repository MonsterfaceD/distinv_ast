\begin{abstract}
Almost-sure termination means that a probabilistic program terminates
with probability one. For sampling algorithms, this property is essential
to ensure that no probability mass is lost through nontermination.
Rejection and restart, however, can make termination arguments difficult.

We present a distribution-based proof rule for almost-sure termination
of fully probabilistic while-loops with loop-free bodies and fixed
choice probabilities. The rule adapts an existing two-certificate
approach from probabilistic control-flow graphs to complete loop
iterations. A variant function captures probabilistic progress, while a
nonnegative supermartingale function bounds the probability of
reaching states in which the variant takes large values.
Both certificates need to be specified only at the start of each
loop iteration. The rule additionally requires a state-based invariant, which can
be obtained from the support of a distributional invariant
established to prove output correctness. We prove soundness and relative completeness
and apply the rule to the Fast Dice Roller, the Fast Loaded Dice Roller,
and Han--Hoshi sampling.

We further implement a prototype that synthesises guarded affine
and piecewise-affine certificates from supplied invariants using
the semantics of a single loop iteration. The prototype synthesizes certificates for
random-walk and sampler examples, including an almost-surely terminating
loop with infinite expected runtime.

\end{abstract}
